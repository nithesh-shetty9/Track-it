# TrackIt

TrackIt is a modern project and task management platform built with React. It combines **personal productivity** with **team collaboration**, allowing users to manage private tasks while working with others on shared projects.

The project is currently being developed **frontend-first**. The backend will be added later after completing the MERN fundamentals.

## ✨ Features

### Personal Tasks

* Create and manage private tasks
* Set task priority and deadlines
* Track task status
* Search, filter, and sort tasks

### Collaborative Projects

* Create projects
* View project details and progress
* Join projects using a project code
* Manage project members
* Assign tasks to project members
* Track project deadlines and progress

### Project Updates

* Project owners can publish updates
* Members can comment on updates
* View project communication in one place

### Dashboard

* Overview of personal tasks
* Project statistics
* Today's tasks
* Upcoming deadlines
* Recent activity
* Notifications

### UI & UX

* Responsive design
* Light and dark mode
* Modern dashboard interface
* Loading states
* Error states
* Empty states
* Form validation
* Accessible and reusable components

## 🚀 Getting Started

Clone the repository:

```bash
git clone <your-repository-url>
```

Navigate into the project:

```bash
cd trackit
```

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```

The application will be available at the local development URL provided by Vite.
